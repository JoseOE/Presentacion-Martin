5–6 · ACL en Gerencia y acceso libre en Sucursal

5ACL extendida PC2_PC3

Aplicada in en G0/0 de Gerencia (cerca del origen).

ip access-list extended PC2_PC3
 permit tcp 192.168.10.0 0.0.0.255 host 10.0.0.2 eq ftp
 deny   tcp 192.168.10.0 0.0.0.255 host 10.10.0.3 eq www
 deny   tcp 192.168.10.0 0.0.0.255 host 10.10.0.3 eq 443
 permit ip any any
interface g0/0
 ip access-group PC2_PC3 in

! Verificación
show access-lists   → contadores (matches)

6PC0 y PC1 · acceso libre

No hay ACL en Sucursal y su tráfico no cruza la G0/0 de Gerencia, así que llegan a FTP y a la web sin filtro.

OrigenFTP 10.0.0.2Web www.asr.com
PC0 / PC1PermitidoPermitido
PC2 / PC3PermitidoBloqueado

La última línea permit ip any any evita el deny implícito, que bloquearía DNS, ping y los datos de FTP.
